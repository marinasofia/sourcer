Sourcer.

A job matching agent I built and run on a schedule. It scans the public boards of fintech and AI companies plus verified internship lists, extracts every relevant posting with the Claude API, scores it 0 to 100 against my skills, verifies each listing is live at the source, and filters to roles matching my level. Employers are shown by sector rather than by name: the point is that the scoring is consistent, not which companies are hiring. Pipeline source on GitHub.

Scores are a weighted match between each posting's stated requirements and my skills vector, computed with schema validated Claude Haiku calls, deterministic pre filters, and per listing source verification. Refreshed on a weekday schedule by GitHub Actions from a sanitized export; detailed scoring internals stay private. All data comes from public job boards.
